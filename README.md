## Technology and design

The portfolio uses **HTML5 and CSS3** and is hosted on **Vercel**. It is a static, single-page website with no JavaScript runtime, application dependencies, database, or build step.

The layout adapts to desktop and mobile screens. It includes semantic page sections, a keyboard skip link, visible focus styles, and reduced-motion support. Typography uses DM Sans and Manrope from Google Fonts, with local font fallbacks.

## Run locally

Clone the repository and serve the website with Python 3:

```powershell
git clone https://github.com/Athithiya02/athithiya-portfolio.git
cd athithiya-portfolio
python -m http.server 5178 --bind 127.0.0.1 --directory dist
```

Open [http://127.0.0.1:5178](http://127.0.0.1:5178). Press `Ctrl+C` in the terminal to stop the server. No package installation is required to preview the site.

## Update the content

Edit `dist/index.html` to update project descriptions, experience, skills, or links. Edit `dist/styles.css` to change the design. Replace the documents in `dist/assets/` when updating the resume or certificates, and update the corresponding links if filenames change.

## Deploy to Vercel

The included `vercel.json` selects `dist` as the output directory and disables the build command.

To deploy your own copy through the Vercel dashboard, import this repository, select the **Other** framework preset, leave the build command empty, and use **dist** as the output directory.

Alternatively, with the Vercel CLI installed:

```powershell
vercel.cmd login
vercel.cmd link
vercel.cmd deploy --prod
```

On macOS or Linux, use `vercel` instead of `vercel.cmd`. Local Vercel configuration and environment files are excluded from Git. This site requires no application environment variables.
