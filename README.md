## Technology and design

The portfolio uses **HTML5 and CSS3** and is hosted on **Vercel**. It is a static, single-page website with no JavaScript runtime, application dependencies, database, or build step.

The layout adapts to desktop and mobile screens. It includes semantic page sections, a keyboard skip link, visible focus styles, and reduced-motion support. Typography uses DM Sans and Manrope from Google Fonts, with local font fallbacks.

## Repository structure

```text

  index.html             # Main page and portfolio content

```

`dist/` contains the authored website files directly; it is not generated by a build tool.
